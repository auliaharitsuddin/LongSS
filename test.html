🚀 Features

Automatic Stitching

The extension automatically captures multiple screenshots and stitches them together seamlessly, ensuring no content is missed.

High Quality Output

All screenshots are captured in high resolution PNG format, preserving image quality and text clarity.

Visual Feedback

Real-time progress indicators and status messages keep you informed throughout the capture process.

No Data Collection

Your privacy is protected - all processing happens locally on your device with no external data transmission.

Cross-Browser Support

Works seamlessly across Chrome, Edge, Brave, Opera, and Firefox (with minor adjustments).

💻 Code Example

Here's a sample of how the extension captures screenshots:

// Capture full page screenshot async function captureFullPage(tab, dimensions) { const screenshots = []; const viewportHeight = dimensions.viewportHeight; const totalHeight = dimensions.scrollHeight; const numScreens = Math.ceil(totalHeight / viewportHeight); for (let i = 0; i < numScreens; i++) { const scrollTop = i * viewportHeight; await scrollToPosition(tab, scrollTop); const dataUrl = await captureVisibleTab(tab); screenshots.push({ dataUrl, offsetY: scrollTop }); } return stitchImages(screenshots, dimensions); }
