# 🚀 Quick Start Guide - LongSS

Get started with LongSS in under 5 minutes!

## 📦 Installation (2 minutes)

### For Chrome/Edge/Brave/Opera:

1. **Download** this extension folder
2. Open your browser's extensions page:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
   - Opera: `opera://extensions/`
3. **Enable** "Developer mode" (toggle in top-right)
4. Click **"Load unpacked"**
5. Select the `LongSS` folder
6. **Done!** The extension icon appears in your toolbar

💡 **Tip**: Pin the extension by clicking the puzzle icon 🧩 in your toolbar

---

## 🎯 Using LongSS (3 minutes)

### 1️⃣ Full Page Screenshot

**Best for**: Entire web pages, long articles, documentation

1. Navigate to any webpage
2. Click the LongSS icon
3. Click **"Full Page Screenshot"**
4. Wait a few seconds
5. Screenshot downloads automatically ✅

**Example uses**:
- Save full blog posts
- Capture complete product pages
- Archive documentation

---

### 2️⃣ Framed Screenshot

**Best for**: Professional presentations, social sharing

1. Navigate to the page you want to capture
2. Click the LongSS icon
3. Click **"Framed Screenshot"**
4. Styled screenshot downloads instantly ✅

**Example uses**:
- Portfolio pieces
- Marketing materials
- Professional presentations

---

### 3️⃣ Scroll Recording

**Best for**: Social media feeds, chat threads, dynamic content

1. Open a page with scrollable content
2. Click the LongSS icon
3. **Hold down** the **"Hold to Record Scroll"** button
4. While holding, **scroll** through the content
5. **Release** when done (or wait 10 seconds max)
6. Screenshot processes and downloads ✅

**Example uses**:
- Twitter/X threads
- Instagram feeds
- YouTube comments
- Facebook timelines
- Chat conversations

**Tips**:
- Scroll at a moderate pace
- Keep the button pressed while scrolling
- Progress bar shows recording time
- Auto-stops at 10 seconds

## 💡 Pro Tips

### Getting Better Results:

1. **Full Page Capture**:
   - Wait for page to fully load
   - Close any popups or modals
   - Disable auto-playing videos

2. **Framed Screenshots**:
   - Position important content in viewport
   - Works with current view only
   - Great for highlighting specific sections

3. **Scroll Recording**:
   - Practice the hold-and-scroll motion
   - Scroll smoothly and consistently
   - Perfect for capturing stories or feeds
   - Release early to capture just what you need

## 🔍 Keyboard Workflow

Quick workflow for power users:

1. `Ctrl + Click` on extension icon (opens in new flow)
2. Navigate with mouse or keyboard
3. Click to capture
4. `Ctrl + J` to view downloads (Chrome)

---

## 📁 Where Are My Screenshots?

Screenshots are saved to your browser's default download folder:

- **Windows**: `C:\Users\YourName\Downloads\`
- **Mac**: `/Users/YourName/Downloads/`
- **Linux**: `/home/YourName/Downloads/`

**Filename format**:
- Full page: `longss-fullpage-[timestamp].png`
- Framed: `longss-framed-[timestamp].png`
- Scroll: `longss-scroll-[timestamp].png`

## ❓ Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| Extension icon not showing | Pin it from the puzzle icon menu |
| Can't capture page | Check if it's a browser internal page (chrome://) |
| Screenshot incomplete | Wait for page to fully load |
| Scroll recording too short | Hold button longer, scroll slower |
| No download happening | Check download permissions in browser |
