# 🚀 START HERE - LongSS Extension

Welcome to LongSS! This guide will get you up and running in minutes.

## 📦 What You Have

This is a **complete browser extension** for capturing long screenshots with three powerful modes:
- 📄 **Full Page** - Entire webpage from top to bottom
- 🖼️ **Framed** - Current view with professional frame
- 📜 **Scroll Recording** - Hold button and scroll (max 10s)

## ⚡ Quick Start (3 Steps)

### Step 1: Install the Extension (2 minutes)

#### For Chrome/Edge/Brave/Opera:
1. Open your browser
2. Type in address bar:
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`
   - Brave: `brave://extensions/`
   - Opera: `opera://extensions/`
3. Turn ON "Developer mode" (toggle in top-right)
4. Click "Load unpacked"
5. Select this **LongSS** folder
6. Done! 🎉

#### Icon not showing?
Click the puzzle icon (🧩) in toolbar → Find LongSS → Click pin

---

### Step 2: Test It (1 minute)

1. Open `test.html` from this folder in your browser
2. Click the LongSS icon in your toolbar
3. Try each button:
   - "Full Page Screenshot" - captures whole page
   - "Framed Screenshot" - captures with frame
   - "Hold to Record Scroll" - hold, scroll, release

---

### Step 3: Use It Anywhere!

Now use it on any website:
- News articles
- Documentation
- Social media feeds
- Product pages
- Anything you want to capture!

## 🎯 Three Capture Modes Explained

### 1. Full Page Screenshot 📄
**When to use**: Save entire web pages
**How it works**: 
- Click the button
- Extension scrolls automatically
- Captures and stitches all sections
- Downloads complete image

**Perfect for**:
- Documentation
- Long articles
- Product pages
- Blog posts

---

### 2. Framed Screenshot 🖼️
**When to use**: Professional presentation
**How it works**:
- Click the button
- Captures current view
- Adds white frame and shadow
- Downloads styled image

**Perfect for**:
- Portfolio
- Presentations
- Social media posts
- Marketing materials

---

### 3. Scroll Recording 📜
**When to use**: Dynamic/scrolling content
**How it works**:
- **HOLD** the button down
- Scroll while holding
- **RELEASE** when done (or wait 10s)
- Downloads stitched image

**Perfect for**:
- Twitter/X threads
- Instagram feeds
- YouTube comments
- Chat conversations
- Facebook timelines

💡 **Tip**: A red "Recording..." indicator appears at the top while recording!

## 🔧 Troubleshooting Quick Fixes

| Problem | Quick Fix |
|---------|-----------|
| Can't see extension icon | Click puzzle icon 🧩 and pin LongSS |
| Extension won't load | Make sure Developer Mode is ON |
| Screenshot not downloading | Check your Downloads folder |
| Page not capturing | Refresh page and try again |
| Scroll recording not working | Hold button WHILE scrolling |
